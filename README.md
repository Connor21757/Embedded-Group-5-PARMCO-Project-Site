# PARMCO project site (Checkpoint 3)

Static site for GitHub Pages. No build step.

## Publish

1. Create a GitHub repository (for example `parmco`).
2. Upload everything in this folder to the repository root, so `index.html` is at the top level.
3. In the repository, open Settings, then Pages. Under Build and deployment choose "Deploy from a branch", pick the `main` branch and the `/ (root)` folder, and save.
4. After a minute the site is live at `https://<your-username>.github.io/<repository-name>/`.

## Contents

- `index.html`, `hardware.html`, `software.html`, `testing.html`, `ai-process.html`: the pages
- `css/style.css`, `js/protractor.js`: styling and the angle explorer on the home page
- `img/`: schematic and software architecture diagram
- `docs/`: the AI-generated Checkpoint 2 and Checkpoint 3 documentation PDFs
