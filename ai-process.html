AI process

AI is the primary author of this project: the Pi code, the circuit documentation, the software documentation and this site.

What the AI produced

  • The C and ARM assembly control software for the Pi.
  • The circuit schematic, parts list, assembly instructions and “how it works” analysis.
  • The software documentation, including library attribution and code flags.
  • This site.

What the AI did not write

The class RP4 library (E4235) is provided by the instructor. The AI calls it, and every use of it is credited to the class library.

Human edits

Any human change to code is marked with beginning and ending comments and keeps the AI original as a comment. The code-flag scan of the Checkpoint 3 source files found no human edits.

Confirming the AI’s results

AI can be confidently wrong, especially about circuits, so each result is checked on the hardware and against an independent reference, as the testing page describes. The record of the AI interactions is kept in the class repository rather than on this site.
